# Demo v1 验收记录

日期：2026-09-23  
版本：demo-1.2.0  
依据：轻量 Demo 开发方案 D01–D14、设计规范 v1.1 的大图卡片 / 手势 / 撤回要求，以及 PRD 的核心业务流程。完整 MVP 的后台、在线模型和跨用户指标不属于本次范围。

**结果：7 / 7 组本次改版浏览器场景通过。** 冷启动散落卡片、左右滑动语义、三阶段流转、系统餐次、默认 / 手动位置、图片轮换和推荐闭环均已验证；没有捕获到 JavaScript 页面异常，正常体验没有外部网络请求。

## 验证环境与方法

- Microsoft Edge 153.0.4234.48（Chromium），Windows，本地静态 HTTP 服务。
- 原生 JavaScript + Playwright 的一次性检查脚本；没有给产品引入测试框架、打包或运行依赖。
- 视口：390 × 844、360 × 640；本轮重点检查首页图片扩展后的窄屏布局。
- 使用 Playwright 检查本轮状态流转和本地存储；历史版本的手势、反馈、撤回和异常验收仍保留在上一轮实现中。
- 运行原始结果：[qa/results.json](qa/results.json)。

## 本轮修复

- 撤销了切后台时重复写入整个状态，避免旧页面覆盖较新的本地记录；业务动作本身已即时保存。
- 处理原生触控从图片子元素向卡片转移捕获时的事件冒泡，避免一次正常滑动被取消。
- 加入弹层 Tab 焦点循环及触发控件焦点恢复。
- 模拟餐后回答独立于正式反馈；未做选择也可单独预览，且不记录虚假的认可。
- 首页改为三段式散落卡排除冷启动；价格和距离使用低价 / 实惠 / 精致及近 / 适中 / 远分档，并保留“不考虑”卡片；餐次改为系统按时间判断。
- 默认位置调用浏览器地理位置读取并保留手动演示出发点切换；静态 Demo 无真实校园坐标映射。
- 忌口加入常见选项及手动关键词筛选，手动内容仍明确标为概念筛选。

## 未验证与实际边界

- 尚未在实体 iPhone / Android 手机、Safari、读屏软件上手动验证。系统侧滑返回、实体设备多指缩放及不同输入法仍需要真机检查；浏览器触控仿真不能替代这些结论。
- 200% 使用浏览器根字号放大验证内容适配，不是所有操作系统字体缩放模式的穷举。
- 当前服务仅本机运行；没有进行公网发布、远程反馈收集、真实校园供给核验或真实用户效果实验。
- 仅保留本机最近选择、当前会话与有限本地反馈。更换浏览器 / 来源、手动清存储或多端使用均不会同步。
- 素材授权边界见 [assets/SOURCES.md](assets/SOURCES.md)；图片和供给均为示意。

## 复跑（可选）

先按 [README](README.md) 启动本地静态服务。若环境已安装 Playwright，可执行：

```powershell
node demo/qa/verify.cjs
```

若 Playwright 装在其他位置，用 `PLAYWRIGHT_MODULE` 指向该模块；默认使用已安装的 Edge，也可通过 `BROWSER_CHANNEL` 改为 `chrome`。通过 `DEMO_URL` 指定另一个本地预览地址。检查只操作独立无头浏览器上下文，不会清除日常浏览器的 Demo 记录。
